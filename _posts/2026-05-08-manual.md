Gemini와의 대화
네이버maps dynamic map 은 한달무료 호출수는? 호출수가 더많은 네이버 지도서비스는?
네이버 지도 API(현재 NAVER Cloud Platform의 Maps 서비스)의 호출 정책에 대해 안내해 드립니다. 2025년부터 지도 서비스 통합 및 개편이 진행되었으므로, 최신 정보를 바탕으로 정리해 드립니다.

1. Dynamic Map 월간 무료 호출수
네이버 지도 API 중 가장 많이 쓰이는 Dynamic Map(웹/모바일 SDK)의 무료 제공량은 다음과 같습니다.

월간 무료 제공량: 10,000,000건 (1천만 건)

기준: Web Dynamic Map과 Mobile Dynamic Map(Android, iOS SDK) 호출 수를 합산하여 계산합니다.

특이사항: 타사(카카오 30만 건/일 등) 대비 월간 단위로 매우 넉넉한 쿼터를 제공하는 것이 특징입니다.

2. 지도 서비스별 무료 호출수 비교
호출수가 가장 많은 서비스는 단연 Dynamic Map입니다. 서비스 성격에 따라 무료 제공량이 다르게 책정되어 있습니다.

서비스 구분	월간 무료 제공량	특징
Dynamic Map	10,000,000건	가장 많은 호출수 제공. JS/Android/iOS용 동적 지도
Static Map	3,000,000건	정지된 지도 이미지 생성 (이미지 태그 호출)
Geocoding	3,000,000건	주소를 좌표로 변환
Reverse Geocoding	3,000,000건	좌표를 주소로 변환
Directions 5 / 15	60,000건	경로 탐색 및 길찾기 (호출수가 가장 적음)
💡 주의사항 (2026년 기준)
서비스 통합: 과거 'AI NAVER API' 내에서 제공되던 지도 API는 종료되었으며, 현재는 네이버 클라우드 플랫폼(NCP)의 [Maps] 상품으로 신청해야만 위와 같은 무료 혜택을 받을 수 있습니다.

초과 시 과금: 무료 쿼터 초과 시에는 자동으로 유료 전환되거나 서비스가 차단될 수 있으므로, 현재 개발 중이신 배달길(Baedalgil) 앱의 예상 사용자 수에 맞춰 콘솔에서 사용량 알림 설정을 해두시는 것을 추천합니다.

배달 파트너를 위한 앱이라면 지도 호출이 빈번할 텐데, 네이버의 1천만 건 쿼터는 소규모~중견 서비스까지는 충분히 무료로 커버 가능한 수준입니다.

혹시 특정 API(예: 경로 탐색)의 쿼터가 부족할 것 같아 걱정되시는 부분이 있나요?

현재 월 600000 일200000 건무료 인데 확인바랍니다
네이버 지도 API의 무료 호출 정책에 대해 혼동이 있으신 부분 명확히 짚어드리겠습니다.

말씀하신 '월 60만 건 / 일 20만 건' 기준은 과거 네이버 지도 API(공통)나 구형 정책에서 언급되던 수치일 가능성이 높습니다. 하지만 2025년 3월에 출시된 신규 'Maps' 단독 상품과 2026년 현재 기준으로는 정책이 아래와 같이 확정되어 운영되고 있습니다.

1. 최신 무료 쿼터 확인 (2026년 기준)
현재 네이버 클라우드 플랫폼(NCP)에서 제공하는 Web/Mobile Dynamic Map의 무료 호출 수는 제가 앞서 말씀드린 월 1,000만 건이 맞습니다.

Dynamic Map (동적 지도): 월 10,000,000건 무료

Static Map (정적 지도): 월 3,000,000건 무료

Geocoding (주소 변환): 월 3,000,000건 무료

중요: 과거 'AI NAVER API' 항목 아래에 있던 지도 서비스는 2025년 7월부로 무료 혜택이 종료되었습니다. 만약 기존 프로젝트가 'AI NAVER API' 소속이라면 무료 혜택 없이 100% 과금될 수 있으니, 반드시 신규 'Maps' 상품으로 이전하셨는지 확인이 필요합니다.

2. 왜 숫자가 다르게 느껴질까요?
사용자께서 알고 계신 수치는 아래 상황 중 하나일 수 있습니다.

일일 한도 설정: 네이버 콘솔에서 과금을 방지하기 위해 사용자가 직접 일일 한도를 20만 건으로 설정해두셨을 수 있습니다. (무료 범위가 월 1,000만 건이라도 일일 제한을 걸어두는 것이 안전하기 때문입니다.)

타사 서비스(카카오 등): 카카오 지도의 경우 Web API 기준 일 30만 건 등 네이버보다 훨씬 적은 쿼터를 제공합니다.

특수 API: 'Directions 5(길찾기)' 같은 특정 API는 무료 쿼터가 월 6만 건으로 매우 적습니다. 혹시 길찾기 API 호출량을 말씀하시는 것이라면 월 6만 건이 맞습니다.

3. 확인 방법
가장 확실한 방법은 지금 운영 중이신 네이버 클라우드 플랫폼 콘솔에서 직접 확인하는 것입니다.

[Console] 접속 → [Services] → [Maps] 이동

[Usage] 또는 [Quota] 탭 클릭

올려주신 콘솔 화면 이미지를 통해 정확한 상태를 확인했습니다. 현재 적용되어 있는 쿼터는 다음과 같습니다.

1. 현재 설정된 쿼터 확인
이미지 내 Dynamic Map 항목을 보면 우측에 다음과 같이 표시되어 있습니다.

당일 사용량: 0 / 200,000회 (일일 한도)

당월 사용량: 728 / 6,000,000회 (월간 한도)

2. 왜 1,000만 건이 아닌가요?
네이버 클라우드 플랫폼의 기본 무료 제공량은 월 1,000만 건이 맞지만, 화면에 6,000,000회로 표시되는 이유는 '한도 설정' 때문일 가능성이 높습니다.

한도 및 일일 설정: 이미지 중앙의 [인증 정보] 탭 옆에 있는 [한도 및 일일 설정] 탭을 클릭해 보세요.

여기서 사용자가 직접 월간 한도를 600만 건, 일일 한도를 20만 건으로 제한해 두었을 수 있습니다. 이는 실수로 인한 과도한 호출이나 비용 발생을 막기 위해 개발자가 직접 설정하는 값입니다.

3. 호출수가 더 많은 서비스는?
현재 화면에 등록된 Dynamic Map이 네이버 지도 서비스 중 가장 많은 무료 호출수를 제공하는 서비스가 맞습니다.

Web/Mobile Dynamic Map: 월 최대 1,000만 건까지 무료로 확장 가능합니다. (현재 600만 건으로 설정되어 있다면 설정 변경을 통해 늘릴 수 있습니다.)

반면, Static Map이나 Geocoding 등은 월 300만 건으로 무료 범위가 더 적습니다.

결론 및 조언
현재 배달길(baedalgil) 앱 프로젝트에 설정된 월 600만 건, 일 20만 건은 초기 서비스 단계에서 매우 충분한 양입니다.

만약 서비스 규모가 커져서 600만 건 이상이 필요하다면, [한도 및 일일 설정] 탭에서 월간 한도를 10,000,000회까지 상향 조정하시면 됩니다. 그 범위까지는 별도의 추가 비용 없이 무료로 이용 가능합니다.

"1 부터 6,000,000 까지의 숫자들을 입력하세요."

이 메시지는 현재 계정 상태에서 설정 가능한 최대 한도가 600만 건으로 제한되어 있다는 뜻입니다.

1. 왜 1,000만 건이 아닌가요?
네이버 클라우드 플랫폼의 무료 등급(Free Tier) 기준이 변경되었거나, 현재 사용 중인 계정의 요금제(예: 개인/사업자 여부 또는 가입 시점)에 따라 기본 제공되는 '무료 한도'가 월 600만 건으로 책정된 것으로 보입니다.

결론: 사용자님의 현재 조건에서는 월 6,000,000회 / 일 200,000회가 최대로 누릴 수 있는 무료 호출수입니다. (제가 처음에 말씀드린 1,000만 건은 일반적인 비즈니스 요금제나 최상위 등급 기준일 수 있으며, 개인 계정은 600만 건이 최대치인 경우가 많습니다.)

2. 호출수가 더 많은 서비스가 있나요?
아니요, 네이버 지도 API 중에서 Dynamic Map의 600만 건이 가장 많은 호출수를 제공하는 서비스입니다. 다른 API들(Static Map, Geocoding 등)은 이보다 훨씬 적은 300만 건 수준입니다.

현재 최상의 조건입니다: 월 600만 건이면 하루에 약 20만 번 지도를 띄울 수 있는 양입니다. 배달길(Baedalgil) 앱의 초기 운영 단계에서는 사실상 무제한에 가까울 정도로 넉넉한 양이니 안심하고 개발하셔도 됩니다.

# 배달길(Baedalgil) 서비스 상세 사용 설명서

본 설명서는 배달 파트너 및 라이더분들을 위한 위치 기반 커뮤니티 애플리케이션 **'배달길(Baedalgil)'**의 효율적인 사용 방법과 주요 기능을 상세히 안내합니다.

---

## 1. 서비스 개요
**배달길**은 Flutter 프레임워크와 Naver Maps API를 기반으로 구축된 실시간 위치 공유 및 배달 파트너 전용 커뮤니티입니다. 단순한 지도 앱을 넘어, 라이더 간의 실시간 정보 교류를 통해 보다 안전하고 효율적인 배달 환경을 조성하는 것을 목표로 합니다.

---

## 2. 주요 기능 상세 안내

### 2.1 실시간 배달 지도 (Naver Dynamic Maps)
앱의 메인 화면은 네이버 지도를 기반으로 하며, 다음과 같은 인터페이스를 제공합니다.
* **실시간 위치 트래킹:** 사용자의 현재 위치를 GPS 기반으로 정확하게 표시합니다.
* **주변 라이더 표시:** 지도상에 현재 활동 중인 다른 배달 파트너들의 위치가 아이콘으로 표시되어, 지역별 라이더 밀집도를 직관적으로 파악할 수 있습니다.
* **배달길 경로 최적화:** 목적지 설정 시 라이더에게 최적화된 이륜차 통행 가능 경로를 제안합니다.

### 2.2 위치 공유 및 상태 관리
* **업무 모드 토글:** '업무 시작' 버튼을 누르면 실시간 위치 공유가 시작되며, '업무 종료' 시 위치 추적이 즉시 중단되어 프라이버시를 보호합니다.
* **상태 메세지:** 자신의 상태(예: '조리 대기 중', '엘리베이터 이동 중', '식사 중')를 설정하여 주변 동료들에게 상황을 알릴 수 있습니다.

### 2.3 지역 기반 실시간 커뮤니티
* **실시간 제보 게시판:** 사고 발생, 도로 통제, 기상 변화(갑작스러운 소나기 등), 혹은 경찰 단속 구간 정보를 즉시 공유하고 푸시 알림을 받을 수 있습니다.
* **매장 정보 메모:** 특정 매장의 픽업 위치, 주차 편의성, 사장님의 성향 등 배달 업무에 실질적으로 도움이 되는 정보를 '핀(Pin)' 형태로 지도에 남기거나 공유합니다.

### 2.4 개인 운행 통계
* **운행 리포트:** 당일 주행 거리, 운행 시간, 완료 건수를 자동으로 기록하여 대시보드 형태로 제공합니다.
* **수익 분석:** 입력된 정보를 바탕으로 시간당 효율을 계산하여 어떤 시간대에 어떤 지역에서 활동하는 것이 유리한지 분석해 줍니다.

배달길 앱의 모든 기능을 원활히 사용하기 위해서는 다음 권한 허용이 필수적입니다.

* **프로필 설정:** 자신의 활동명(닉네임)과 주요 활동 지역을 설정하십시오.

## 4. 고급 활용 팁

* **네트워크 데이터 절약:** 배달길은 고효율 데이터 전송 방식을 사용하여 이동 중에도 데이터 소모를 최소화합니다.
* **지도 호출 최적화:** 월 600만 건의 넉넉한 네이버 지도 API 쿼터를 활용하므로, 지도를 자주 새로고침하거나 확대/축소해도 서비스 이용에 차질이 없습니다.
* **GetX 기반의 빠른 속도:** 최신 상태 관리 기술을 적용하여 메뉴 간 이동이나 데이터 로딩 속도가 매우 빠릅니다.

## 5. 자주 묻는 질문 (FAQ)

**Q: 위치 공유를 켜두면 개인정보가 노출되지 않나요?**
A: 사용자의 실제 이름이나 상세 정보는 노출되지 않으며, 오직 설정한 닉네임과 위치 아이콘만 표시됩니다. 또한 언제든지 업무 모드를 종료하여 공유를 중단할 수 있습니다.

**Q: 데이터 사용량이 걱정됩니다.**
A: 지도 데이터는 캐싱 기술을 통해 재방문 지역의 데이터 소모를 줄이며, 위치 좌표 전송은 텍스트 기반의 초경량 패킷을 사용하여 한 달 내내 사용해도 데이터 부담이 적습니다.
