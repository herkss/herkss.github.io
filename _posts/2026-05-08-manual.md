# 배달길(Baedalgil) 서비스 상세 사용 설명서

본 설명서는 배달 파트너 및 라이더분들을 위한 위치 기반 커뮤니티 애플리케이션 **'배달길(Baedalgil)'**의 효율적인 사용 방법과 주요 기능을 상세히 안내합니다.

---

## 1. 서비스 개요
**배달길**은 Flutter 프레임워크와 Naver Maps API를 기반으로 구축된 실시간 위치 공유 및 배달 파트너 전용 커뮤니티입니다. 단순한 지도 앱을 넘어, 라이더 간의 실시간 정보 교류를 통해 보다 안전하고 효율적인 배달 환경을 조성하는 것을 목표로 합니다.

---

## 2. 주요 기능 상세 안내

### 2.1 실시간 배달 지도 (Naver Dynamic Maps)
앱의 메인 화면은 네이버 지도를 기반으로 하며, 다음과 같은 인터페이스를 제공합니다.
* **실시간 위치 트래킹:** 사용자의 현재 위치를 GPS 기반으로 정확하게 표시합니다.
* **주변 라이더 표시:** 지도상에 현재 활동 중인 다른 배달 파트너들의 위치가 아이콘으로 표시되어, 지역별 라이더 밀집도를 직관적으로 파악할 수 있습니다.
* **배달길 경로 최적화:** 목적지 설정 시 라이더에게 최적화된 이륜차 통행 가능 경로를 제안합니다.

### 2.2 위치 공유 및 상태 관리
* **업무 모드 토글:** '업무 시작' 버튼을 누르면 실시간 위치 공유가 시작되며, '업무 종료' 시 위치 추적이 즉시 중단되어 프라이버시를 보호합니다.
* **상태 메세지:** 자신의 상태(예: '조리 대기 중', '엘리베이터 이동 중', '식사 중')를 설정하여 주변 동료들에게 상황을 알릴 수 있습니다.

### 2.3 지역 기반 실시간 커뮤니티
* **실시간 제보 게시판:** 사고 발생, 도로 통제, 기상 변화(갑작스러운 소나기 등), 혹은 경찰 단속 구간 정보를 즉시 공유하고 푸시 알림을 받을 수 있습니다.
* **매장 정보 메모:** 특정 매장의 픽업 위치, 주차 편의성, 사장님의 성향 등 배달 업무에 실질적으로 도움이 되는 정보를 '핀(Pin)' 형태로 지도에 남기거나 공유합니다.

### 2.4 개인 운행 통계
* **운행 리포트:** 당일 주행 거리, 운행 시간, 완료 건수를 자동으로 기록하여 대시보드 형태로 제공합니다.
* **수익 분석:** 입력된 정보를 바탕으로 시간당 효율을 계산하여 어떤 시간대에 어떤 지역에서 활동하는 것이 유리한지 분석해 줍니다.

---

## 3. 앱 설치 및 설정 방법

### 3.1 권한 설정
배달길 앱의 모든 기능을 원활히 사용하기 위해서는 다음 권한 허용이 필수적입니다.
* **위치(항상 허용):** 백그라운드 상태에서도 위치를 공유하고 실시간 정보를 받기 위해 필요합니다.
* **알림:** 긴급 도로 정보 및 커뮤니티 새 글 알림을 받기 위해 필요합니다.

### 3.2 계정 관리
* **로그인:** 구글 또는 네이버 계정을 이용한 간편 로그인을 지원합니다.
* **프로필 설정:** 자신의 활동명(닉네임)과 주요 활동 지역을 설정하십시오.

---

## 4. 고급 활용 팁

* **네트워크 데이터 절약:** 배달길은 고효율 데이터 전송 방식을 사용하여 이동 중에도 데이터 소모를 최소화합니다.
* **지도 호출 최적화:** 월 600만 건의 넉넉한 네이버 지도 API 쿼터를 활용하므로, 지도를 자주 새로고침하거나 확대/축소해도 서비스 이용에 차질이 없습니다.
* **GetX 기반의 빠른 속도:** 최신 상태 관리 기술을 적용하여 메뉴 간 이동이나 데이터 로딩 속도가 매우 빠릅니다.

---

## 5. 자주 묻는 질문 (FAQ)

**Q: 위치 공유를 켜두면 개인정보가 노출되지 않나요?**
A: 사용자의 실제 이름이나 상세 정보는 노출되지 않으며, 오직 설정한 닉네임과 위치 아이콘만 표시됩니다. 또한 언제든지 업무 모드를 종료하여 공유를 중단할 수 있습니다.

**Q: 데이터 사용량이 걱정됩니다.**
A: 지도 데이터는 캐싱 기술을 통해 재방문 지역의 데이터 소모를 줄이며, 위치 좌표 전송은 텍스트 기반의 초경량 패킷을 사용하여 한 달 내내 사용해도 데이터 부담이 적습니다.
