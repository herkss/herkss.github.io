## 1. 앱 소개

**배달길2**는 배달 라이더를 위한 올인원 관리 앱입니다.

### 주요 기능 한눈에 보기

| 탭 | 기능 |
|---|---|
| 🏠 홈 | 지도 기반 픽업/배달 위치 기록, 위치 메모,AI챗봇 |
| 💬 커뮤니티 | 게시판, 갤러리, 정보 공유 |
| 📡 레이더 | 주변 배달러 실시간 위치 공유, 친구 레이더, 그룹 채팅 |
| 💰 결산 | 수입/지출 관리, 정비 관리, 계산기 |
| 👤 정보 | 내 프로필, 활동 통계 |

## 2. 시작하기

### 2-1. 회원가입

1. 앱 실행 후 **회원가입** 버튼 탭
2. 이메일 / 비밀번호 입력
3. **닉네임 설정** (한글/영문 2~10자, 중복 불가)
4. 이메일 인증 완료 후 로그인

> ⚠️ **주의**: 닉네임은 레이더, 채팅, 커뮤니티 전체에서 표시됩니다. 신중하게 설정하세요.

### 2-2. 소셜 로그인

- **Google 로그인**: 구글 계정으로 빠르게 가입
- **카카오 로그인**: 카카오 계정 연동

> ⚠️ **주의**: 소셜 로그인과 이메일 로그인은 **별개 계정**입니다. 같은 이메일이라도 방식이 다르면 다른 계정으로 처리됩니다.

### 2-3. 로그인 유지

- 앱을 종료해도 로그인 상태가 유지됩니다.
- 로그아웃은 **드로어 메뉴 → 로그아웃**에서 가능합니다.

### 2-4. 회원 탈퇴

**드로어 메뉴 → 하단 회원 탈퇴**

- 이메일 계정: 비밀번호 재확인 후 탈퇴
- Google 계정: Google 재인증 후 탈퇴
- 카카오 계정: 카카오 재인증 후 탈퇴

> ⚠️ **경고**: 탈퇴 시 모든 데이터(수입/지출 기록, 위치 메모, 채팅 이력 등)가 **영구 삭제**됩니다. 복구 불가합니다.

## 3. 홈 탭

### 3-1. 화면 구성

홈 탭은 **네이버 지도** 기반으로 내 위치와 픽업/배달 기록을 시각적으로 확인합니다.

```
┌─────────────────────────────┐
│  [드로어] [공지사항 마퀴]     │  ← 상단
│  [픽업/배달 위치저장 라벨]    │
│                              │
│         지 도                │
│                              │
│  [픽업] [배달]       [오늘]  │  ← 우측 버튼
│                     [어제]   │
│  [위치메모]         [1주]    │
│  [메모보기]         [1달]    │
│  [위치메모불러오기]      [픽업]   │
│  [불러온마커보기]   [배달]   │
│  [내보내기]         [전체]   │
│  [내위치]                    │  ← 좌측 하단
└─────────────────────────────┘
```

### 3-2. 픽업/배달 위치 기록

#### 🟢 픽업 기록
- 우측 상단 **초록색 픽업 버튼** 탭
- 현재 GPS 위치가 지도에 🟢 마커로 저장됩니다.
- **쿨타임**: 10초마다 1회 기록 가능 (쿨타임 중 버튼에 카운트다운 표시)

#### 🔴 배달 기록
- 우측 **빨간색 배달 버튼** 탭
- 현재 GPS 위치가 지도에 🔴 마커로 저장됩니다.

> ⚠️ **주의**: GPS가 켜져 있어야 기록됩니다. GPS 없는 상태에서 버튼을 누르면 "위치를 가져올 수 없습니다" 알림이 표시됩니다.

### 3-3. 기간 필터

우측 버튼으로 표시 기간 선택:

| 버튼 | 내용 |
|---|---|
| 오늘 | 오늘 기록만 표시 |
| 어제 | 어제 기록만 표시 |
| 1주 | 최근 7일 기록 표시 |
| 1달 | 최근 30일 기록 표시 |

### 3-4. 유형 필터

| 버튼 | 내용 |
|---|---|
| 픽업 | 픽업 마커만 표시 |
| 배달 | 배달 마커만 표시 |
| 전체 | 모두 표시 |

### 3-5. 위치 메모

#### 메모 저장
1. 좌측 **위치메모** 버튼 탭
2. 현재 위치의 주소 자동 조회 (카카오 API)
3. 메모 내용 입력 후 **저장**

> ⚠️ **주의사항**:
> - 월 최대 **150개** 메모 가능 (초과 시 저장 불가)
> - 주소 조회 중 로딩 스피너가 표시됩니다. 완료될 때까지 기다리세요.
> - 메모는 Supabase DB에 저장되므로 앱을 재설치해도 유지됩니다.

#### 메모 보기/숨기기
- **메모보기** 버튼: 지도에 🟠 말풍선 마커로 표시
- **메모숨기기**: 동일 버튼 재탭

#### 메모 수정/삭제
- 지도의 메모 마커 탭 → 다이얼로그에서 수정 또는 삭제

### 3-6. 위치메모 내보내기/불러오기

#### 내보내기
1. **내보내기** 버튼 탭
2. 다운로드 폴더에 `위치메모_YYYYMMDD.csv` 파일 저장

CSV 형식:
```
번호, 날짜, 시간, 주소, 위도, 경도, 메모
1, 2026-06-01, 09:30, 전주시 덕진구 ..., 35.xxxx, 127.xxxx, 픽업 완료
```

#### 위치메모 불러오기
1. **CSV불러오기** 버튼 탭
2. 파일 탐색기에서 CSV 파일 선택
3. 지도에 🟢 초록색 말풍선 마커로 표시

> ⚠️ **주의**: 다른 사람이 공유한 CSV 파일도 불러올 수 있습니다. 형식이 맞지 않으면 "유효한 데이터가 없습니다" 알림이 표시됩니다.

### 3-7. 공지사항

- 상단 마퀴(흘러가는 텍스트) 탭 → 전체 공지사항 확인
- 관리자만 공지사항 작성/수정/삭제 가능

## 4. 커뮤니티 탭

### 4-1. 게시판 카테고리

| 카테고리 | 내용 |
|---|---|
| 자유게시판 | 자유롭게 소통 |
| 정보공유 | 배달 관련 정보 |
| 질문/답변 | 궁금한 점 질문 |
| 갤러리 | 사진 공유 |
| 비밀게시판 | 비밀번호 보호 게시글 |

### 4-2. 게시글 작성

1. 커뮤니티 탭 → **작성** 버튼(✏️) 탭
2. 카테고리 선택
3. 제목 / 내용 입력
4. 사진 첨부 (선택)
5. **비밀글** 설정 시 비밀번호 4자리 입력
6. **등록** 버튼 탭

> ⚠️ **주의**: 비밀글 비밀번호는 작성자가 직접 관리합니다. 분실 시 내용 확인 불가합니다.

### 4-3. 댓글

- 게시글 상세 → 하단 댓글 입력창에 입력 후 전송
- 본인 댓글만 삭제 가능

### 4-4. 갤러리

- 사진 중심 게시판
- 이미지 탭하면 전체화면 확인 가능

## 5. 레이더 탭

레이더 탭은 **주변 레이더**와 **친구 레이더** 두 가지 모드가 있습니다.

### 5-1. 주변 레이더

#### 위치 공유 시작
1. 우측 상단 **주변 공개하기** 버튼 탭
2. 최초 1회 **위치 정보 제공 동의** 팝업에서 **동의** 선택
3. 버튼이 **주변 공유중** 으로 변경되며 공유 시작

> ⚠️ **주의사항**:
> - 위치 공유 중에는 배터리 소모가 증가합니다.
> - 앱을 **2분 이상 백그라운드**로 전환하면 자동으로 공유가 중단됩니다.
> - 로그아웃 시 위치 공유가 자동 해제됩니다.

#### 반경 설정
좌측 반경 버튼으로 탐색 범위 설정:

| 버튼 | 반경 |
|---|---|
| 500m | 500미터 이내 |
| 1km | 1킬로미터 이내 |
| 2km | 2킬로미터 이내 |

#### 상태 메시지 (말풍선)
- 하단 **에르메스 색상 입력창**에 메시지 입력 후 전송
- 내 마커 위에 말풍선으로 표시
- **자동 휘발**: 전송 후 **2분** 경과 시 자동 삭제
- 백그라운드 2분 이상 시에도 자동 삭제

> ⚠️ **주의**: 상태 메시지는 주변 모든 배달러에게 보입니다. 개인정보 노출에 주의하세요.

#### 주변인 확인
- **주변 N명** 버튼 탭으로 주변 배달러 목록 표시
- 마커 탭하면 해당 배달러의 이동 수단과 닉네임 확인

### 5-2. 친구 레이더

#### 친구 추가
1. 레이더 탭 → **친구&그룹** 버튼 탭
2. 닉네임 검색으로 친구 요청
3. 상대방이 수락하면 친구 등록 완료

> ⚠️ **주의**: 친구는 최대 **25명**까지 추가 가능합니다.

#### 친구 위치 공유
1. **친구에게 공개** 버튼 탭 → 동의 후 공유 시작
2. 친구들의 마커가 ⭐ 보라색 아이콘으로 표시
3. 친구 목록에서 온라인/오프라인 상태 확인 가능

#### 친구 메시지
- 하단 입력창에 메시지 입력 → 친구에게만 표시
- **자동 휘발**: 2분 후 자동 삭제

### 5-3. 그룹 채팅

#### 그룹 생성
1. **친구&그룹** → **그룹 만들기**
2. 그룹 이름 입력
3. 비밀번호 설정 (선택) — 비밀번호 설정 시 입장 시 비밀번호 필요
4. 활동 지역 자동 설정 (드로어에서 지역 먼저 설정 필요)

> ⚠️ **주의**: 활동 지역 미설정 시 그룹 생성 불가합니다.

#### 그룹 입장

**방식 1 - 비밀번호 입장**
- 그룹 목록에서 원하는 그룹 탭 → 비밀번호 입력 → 입장

**방식 2 - 초대 받아 입장**
- 방장이 초대 발송 → 수락 팝업에서 **입장** 탭

**방식 3 - 입장 요청**
- 그룹 탭 → **입장 요청** → 방장이 수락하면 입장

#### 그룹 채팅 기능

| 기능 | 방법 |
|---|---|
| 메시지 전송 | 하단 입력창 입력 후 전송 |
| 멤버 보기 | 상단 사람 아이콘(👥) 탭 |
| 친구 초대 | 멤버 보기 → 친구 초대 |
| 그룹 나가기 | 멤버 보기 → 그룹 나가기 |
| 그룹 해체 | 방장만 가능 — 멤버 보기 → 그룹 해체 |

#### 방장 권한
- 멤버 강제 퇴장 (멤버 바 X 버튼)
- 강제 퇴장된 멤버는 재초대 전까지 입장 불가
- 입장 요청 수락/거절

#### 입장/퇴장 메시지
- 입장 시: `[닉네임]님께서 입장하셨습니다. 👋`
- 퇴장 시: `[닉네임]님께서 나가셨습니다. 👋`
- 강제 퇴장 시: `[닉네임]님이 강제 퇴장되었습니다. 🚫`

> ⚠️ **주의**: 그룹 해체 시 모든 채팅 기록이 **영구 삭제**됩니다.

## 6. 결산 탭

결산 탭은 **달력**, **대시보드**, **정비**, **계산기** 4개 탭으로 구성됩니다.

### 6-1. 달력 탭

#### 수입 입력
1. 우측 하단 **초록 + 버튼** 탭
2. 입력 방식 선택:
   - **직접입력**: 손으로 직접 입력
   - **음성**: 마이크로 음성 인식

**음성 입력 예시:**
```
"쿠팡이츠 15건 87000원"
"배민 10건 65000원"
"요기요 5건 32000원"
"일반대행 8건 45000원"
```

**입력 항목:**
| 항목 | 설명 |
|---|---|
| 날짜 | 기본값: 오늘 |
| 플랫폼 | 쿠팡이츠/배달의민족/요기요/일반대행/기타 |
| 근무 시간 | 시작-종료 시간 선택 또는 직접 입력 |
| 날씨 | ☀️흐림/☁️흐림/🌧️비/❄️눈 |
| 배달 건수 | 건 단위 |
| 기본 수입 | 원 단위 |
| 팁 | 원 단위 |
| 인센티브 | 원 단위 |
| 주행거리 | km 단위 (정비 탭 자동 연동) |
| 메모 | 특이사항 |

> ⚠️ **주의**: 주행거리를 입력하면 **정비 탭의 차량 주행거리가 자동 업데이트**됩니다. 현재 실제 주행거리를 정확히 입력해주세요.

#### 지출 입력
1. 우측 하단 **빨간 - 버튼** 탭
2. 날짜 / 카테고리 / 금액 / 메모 입력

**지출 카테고리:**
| 아이콘 | 카테고리 |
|---|---|
| ⛽ | 유류비 |
| 🛡️ | 보험료 |
| 🔧 | 수리비 |
| 🍱 | 식비 |
| 📱 | 통신비 |
| 🅿️ | 주차비 |
| 📦 | 기타 |

## 11. 주의사항 및 FAQ

### 🚨 중요 주의사항

#### 위치 관련
- 레이더 기능은 **GPS + 인터넷** 연결 필수
- 위치 공유 중 배터리 소모 증가 — 장시간 사용 시 충전 권장
- 백그라운드 2분 이상 경과 시 위치 공유 자동 중단
- 앱 완전 종료 시 위치 공유 해제됨

#### 채팅 관련
- 그룹 채팅 메시지는 서버에 저장됩니다.
- 그룹 해체 시 모든 채팅 기록 영구 삭제
- 상태 메시지(말풍선)는 2분 후 자동 휘발
- 강제 퇴장 후 재초대 없이는 입장 불가

#### 데이터 관련
- 수입/지출 데이터는 Supabase 서버에 저장
- 위치 메모 월 150개 한도
- CSV 내보내기로 데이터 백업 권장

#### 계정 관련
- 소셜 로그인과 이메일 로그인은 별개 계정
- 회원 탈퇴 시 모든 데이터 영구 삭제 (복구 불가)
- 닉네임 변경은 정보 탭에서 가능

### ❓ 자주 묻는 질문

**Q. 레이더에서 내 위치가 표시되지 않아요.**
> A. 위치 권한이 **항상 허용**으로 설정되어 있는지 확인하세요. GPS가 켜져 있어야 합니다.

**Q. 그룹 채팅에 입장하려는데 "밴" 메시지가 뜹니다.**
> A. 방장에게 강제 퇴장 처리된 상태입니다. 방장에게 재초대를 요청하세요.

**Q. 수입을 입력했는데 달력에 표시가 안 돼요.**
> A. 선택한 연/월과 입력한 날짜가 일치하는지 확인하세요. 상단 좌우 화살표로 월을 이동할 수 있습니다.

**Q. 위치 메모가 150개 한도에 찼어요.**
> A. 불필요한 메모를 삭제하거나, CSV로 내보내기 후 삭제하세요. 한도는 매월 1일 초기화됩니다.

**Q. 상태 메시지가 보내자마자 사라져요.**
> A. 위치 공유가 켜져 있어야 상태 메시지가 작동합니다. **주변 공개하기** 또는 **친구에게 공개** 상태에서 전송하세요.

**Q. 정비 탭에서 소모품이 표시되지 않아요.**
> A. 소모품 탭 → **소모품 선택 및 추가** 버튼을 탭해서 소모품을 등록하세요.

**Q. CSV 불러오기가 실패해요.**
> A. CSV 파일의 형식이 맞는지 확인하세요. 열 순서: `번호, 날짜, 시간, 주소, 위도, 경도, 메모`

**Q. 앱이 갑자기 느려졌어요.**
> A. 앱을 완전히 종료하고 재시작하세요. 위치 공유 중이라면 잠시 해제 후 재시작을 권장합니다.

**Q. 알림이 오지 않아요.**
> A. 기기 설정 → 배달길2 → 알림 허용 여부와 배터리 최적화 설정을 확인하세요.
