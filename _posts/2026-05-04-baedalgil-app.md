## 🚀 프로젝트 소개
**배달길(baedalgil)**은 배달파트너들의 동네 커뮤니티와 위치기록, 근접(500m,1km,2km,3km)반경내의 접속자들과 메세지를 주고받을 수있는 종합 커뮤니티 애플리케이션입니다. 

Flutter 프레임워크를 기반으로 제작되어 안드로이드 환경에서 매끄러운 사용자 경험을 제공하며, **Naver Maps API**를 연동하여 국내 지형에 최적화된 위치 정보를 제공합니다.

---

## ✨ 핵심 기능

### 1. Naver Maps 기반 정밀 위치 서비스
*   **실시간 위치 추적**: 사용자의 현재 위치를 정확하게 파악하여 주변 배달러을 표시합니다.
*   **위치기록**: Naver Cloud Platform의 강력한 지도 엔진을 활용하여 위치기록을 누름으로서 배달을 얼마나 어디에서 완료했느지를 기록함으로서 배달기록을 남길수있는기능.

### 2. Flutter & GetX의 빠른 퍼포먼스
*   **직관적인 UI**: 네온 테마와 깔끔한 디자인을 적용하여 야간 주행 시에도 시인성이 뛰어납니다.
*   **상태 관리**: GetX 라이브러리를 사용하여 데이터 변경 사항이 화면에 즉각적으로 반영됩니다.

### 3. 맞춤형 인터페이스
*   배달러들의 편의성을 고려한 인터페이스 / 경로 히스토리 관리 기능을 통해 배달지의 데이터베이스 구축으로 배달지분포에대한 궁금증해소.

*   **Framework**: Flutter (Dart)
*   **State Management**: GetX
*   **Maps API**: Naver Maps SDK
*   **Theme**: Modern Neon Style
