## 1. 앱 소개

**배달길**은 배달 라이더를 위한 **올인원 실시간 위치 공유 & 커뮤니티 앱**입니다.

### 핵심 기능 한눈에 보기

| 기능 | 설명 |
|------|------|
| 🗺 실시간 레이더 | 반경 내 주변 파트너 / 친구 위치를 지도에서 실시간 확인 |
| 📌 위치메모 | 지도 핀으로 중요 장소(픽업존, 주차, 고객주소 등)를 메모 |
| 💬 그룹 채팅 | 친구·그룹 전용 실시간 채팅, 비밀번호·요청 입장 지원 |
| 📊 결산 | 플랫폼별 수입·지출 기록, 달력·차트 통계 |
| 🔧 정비 | 차량 소모품 교체 주기, 정비 이력 관리 |
| 📰 커뮤니티 | 동네 라이더끼리 정보·에피소드 공유 |
| 🔔 FCM 푸시알림 | 관리자가 전체/지역별 실시간 공지 발송 |

### 기술 스택

- **프레임워크**: Flutter 3 (Dart)
- **백엔드**: Supabase (PostgreSQL + Realtime + Storage)
- **인증**: Supabase Auth (이메일 / 구글 / 카카오)
- **지도**: 네이버 지도 SDK (flutter_naver_map)
- **위치**: GeoFlutterfireplus + Geolocator (GeoHash 서버사이드 필터)
- **푸시**: Firebase Cloud Messaging (FCM)
- **광고**: Google AdMob

## 2. 시작하기 — 계정 & 온보딩

### 2-1. 온보딩 화면

앱을 **처음 설치**하면 5장의 온보딩 슬라이드가 나타납니다.

| 슬라이드 | 내용 |
|----------|------|
| 1 | 실시간 레이더 가동 — 주변 파트너 실시간 확인 |
| 2 | 동네 커뮤니티 — 노하우·에피소드 공유 |
| 3 | 기록과 통계 — 이동 경로 자동 기록 |
| 4 | 안전한 거래와 정보 — 인증 시스템 |
| 5 | 자유로운 소통 — Q&A 카테고리 |

- 우측 상단 **"건너뛰기"** 버튼으로 즉시 로그인 화면으로 이동 가능합니다.
- 온보딩은 **최초 1회만** 표시됩니다. (SharedPreferences에 완료 여부 저장)

---

### 2-2. 회원가입

1. 로그인 화면 → **"회원가입"** 탭 선택
2. **이메일** 주소 입력
3. **비밀번호** (8자 이상) 입력 및 확인
4. **닉네임** 설정 (최대 20자, 중복 불가)
5. **가입하기** 버튼 클릭
6. 가입한 이메일로 **인증 메일** 발송 → 링크 클릭 후 인증 완료
7. 인증 완료 후 로그인 가능

> **주의**: 이메일 인증 전에는 일부 기능이 제한될 수 있습니다.

---

### 2-3. 로그인

1. 앱 실행 → 스플래시 화면 로딩 후 로그인 화면
2. **이메일 / 비밀번호** 입력 후 **로그인** 버튼 클릭
3. 자동 로그인: 이전 로그인 세션이 유효하면 자동으로 메인 화면으로 진입

---

### 2-4. 비밀번호 재설정

1. 로그인 화면 → **"비밀번호를 잊으셨나요?"** 클릭
2. 가입 이메일 주소 입력
3. **재설정 메일 발송** 클릭
4. 수신한 이메일의 링크를 클릭하여 새 비밀번호 설정

> 재설정 링크는 **1시간** 동안 유효합니다.

---

### 2-5. 소셜 로그인 (구글 / 카카오)

#### 구글 로그인
1. 로그인 화면 → **"구글로 계속하기"** 버튼 클릭
2. 구글 계정 선택 또는 입력
3. 권한 허용 후 자동 닉네임 설정 팝업 확인

#### 카카오 로그인
1. 로그인 화면 → **"카카오로 계속하기"** 버튼 클릭
2. 카카오 계정으로 로그인
3. 최초 1회 닉네임 설정 다이얼로그가 표시됩니다

> **소셜 로그인 최초 가입 시**: 닉네임 설정 팝업이 나타납니다. 반드시 닉네임을 입력해야 앱을 사용할 수 있습니다.

## 3. 메인 화면 구조

로그인 후 메인 화면은 **하단 탭바**로 구성됩니다.

```
┌─────────────────────────────────────┐
│           상단 앱바 / 지도           │
│                                     │
│            [메인 콘텐츠]            │
│                                     │
├──────┬──────┬──────┬──────┬──────────┤
│ 🏠홈 │ 🗺레이더│ 👥커뮤 │ 💰결산 │ ℹ️정보 │
└──────┴──────┴──────┴──────┴──────────┘
```

| 탭 | 아이콘 | 주요 기능 |
|----|--------|-----------|
| 홈 | 🏠 | 네이버 지도, 위치메모, 공지 |
| 레이더 | 🗺 | 주변레이더, 친구레이더, 그룹채팅 |
| 커뮤니티 | 👥 | 게시판, 갤러리, 댓글, 검색 |
| 결산 | 💰 | 수입/지출 입력, 달력, 통계, 정비 |
| 정보 | ℹ️ | 내 프로필, 위치통계, 위치메모 통계 |

**좌측 상단 햄버거 버튼(≡)**: 드로어 메뉴 열기  
**상단 알림 벨 아이콘**: 알림 목록 확인

## 4. 홈탭 — 지도 & 위치메모

### 4-1. 지도 기본 조작

홈탭은 **네이버 지도**를 기반으로 합니다.

| 제스처 | 동작 |
|--------|------|
| 한 손가락 드래그 | 지도 이동 |
| 두 손가락 핀치 | 지도 확대/축소 |
| 두 손가락 회전 | 지도 회전 |
| 두 손가락 상하 드래그 | 틸트 조절 |
| 더블탭 | 지도 확대 |

**지도 위 버튼 설명**

| 버튼 | 위치 | 기능 |
|------|------|------|
| 📍 현재위치 | 우측 하단 | 내 위치로 지도 이동 |
| 📌 핀메모 모드 | 우측 하단 | 위치메모 입력 모드 진입 |
| ≡ 드로어 | 좌측 상단 | 드로어 메뉴 열기 |

---

### 4-2. 위성 / 일반 지도 전환

홈탭 상단에 **지도 유형 버튼**이 있습니다.

- **일반 지도**: 기본 도로 지도
- **위성 지도**: 위성 영상 + 도로 정보
- **위성 전용 (도로 감추기)**: 위성 영상만 표시 (도로 레이어 OFF)

> **사용 팁**: 픽업 장소나 골목 진입로 확인 시 위성 지도가 유용합니다.  
> 도로 감추기 모드는 지형지물을 보다 선명하게 확인하고 싶을 때 사용하세요.

---

### 4-3. 핀 메모 (위치 메모)

지도 특정 위치에 메모를 남기는 기능입니다. 단골 픽업존, 주차 금지 구역, 고객 건물 정보 등을 기록할 수 있습니다.

#### 핀 메모 저장 방법

1. 홈탭 우측 하단 **📌 핀메모** 버튼 클릭
2. 화면 상단에 **"지도를 클릭하여 위치를 선택하세요"** 안내 배너 표시
3. 저장하고 싶은 **지도 위 위치를 탭**
4. 카카오 역지오코딩으로 **자동 주소 변환** (카카오 API 활용)
5. **메모 내용 입력** 다이얼로그 표시
6. 제목·내용 작성 후 **저장** 클릭

#### 핀 메모 조회 / 수정 / 삭제

- 지도에 표시된 **📌 핀 아이콘** 클릭 → 상세 팝업
- 팝업 내 **수정 / 삭제** 버튼 제공

#### 주의사항

- 위치메모는 **주소 변환 시 사용량이 차감**됩니다.
- 월별 사용량 한도는 **정보탭 → 위치메모 통계**에서 확인 가능합니다.
- 오프라인 상태에서는 메모 저장이 불가합니다.

---

### 4-4. 위치메모 불러오기

이전에 저장한 위치메모를 지도에 한 번에 표시합니다.

1. 홈탭 상단 **"위치메모 불러오기"** 버튼 클릭
2. 저장된 모든 위치메모가 지도에 핀으로 표시됨
3. 다시 클릭하면 핀 숨김

> **자주 묻는 질문**: "불러오기 버튼이 안 보여요"  
> → 홈탭 상단 작은 버튼들 중 아이콘 형태로 표시됩니다. 화면을 스크롤하거나 버튼 영역을 확인해 주세요.

---

### 4-5. 공지 마퀴 (스크롤 배너)

홈탭 하단에 **공지사항이 흘러가는 배너(마퀴)**가 표시됩니다.

- 관리자가 등록한 공지를 실시간으로 표시
- 스크롤 속도는 자동 조절
- 공지 배너를 탭하면 상세 내용 확인 가능 (향후 업데이트 예정)

## 5. 레이더탭 — 실시간 위치 공유

레이더탭은 **주변레이더**와 **친구레이더** 두 가지 모드로 구성됩니다.

### 5-1. 주변레이더

반경 내 위치를 공유 중인 **모든 사용자**(익명 포함)를 지도에서 확인합니다.

#### 시작하기
1. 레이더탭 → **"🗺 주변레이더"** 탭 선택
2. **위치 공유 토글 ON** → 위치 동의서 확인 후 공유 시작
3. 지도에 파란 원(반경)과 주변 파트너 마커 표시

#### 주요 UI
| 요소 | 설명 |
|------|------|
| 반경 슬라이더 | 레이더 탐지 반경 조절 (500m ~ 5km) |
| 위치 공유 토글 | ON/OFF로 내 위치 공유 여부 결정 |
| 파트너 마커 | 주변 라이더 아이콘 (이동수단 유형별 표시) |
| 상태 메시지 | 각 파트너 상태 메시지 표시 |
| 현재위치 버튼 | 내 위치로 지도 이동 |

#### 주변레이더 채팅
- 주변레이더 하단 **채팅 입력창**으로 주변 파트너와 실시간 소통
- 반경 내 사용자 모두에게 메시지 전달

#### 이동수단 설정
- 드로어 또는 레이더 설정에서 이동수단(오토바이/자전거/킥보드/도보) 선택 가능
- 선택한 이동수단 아이콘이 내 마커에 표시됨

---

### 5-2. 친구레이더

**친구 목록에 등록된 사용자**의 위치만 별도 지도에 표시합니다.

#### 시작하기
1. 레이더탭 → **"⭐ 친구레이더"** 탭 선택
2. **위치 공유 토글 ON** (친구 전용 공유, 주변레이더와 독립)
3. 친구 목록의 위치가 지도에 표시됨

#### 주요 UI
| 요소 | 설명 |
|------|------|
| 친구 위치 마커 | 친구 닉네임 + 마커 색상 |
| 위치 공유 토글 | 친구레이더 전용 공유 여부 |
| 온라인 상태 | 친구 마커 색상으로 온라인/오프라인 구분 |
| 그룹 버튼 | 그룹 목록 바로가기 |
| 친구 버튼 | 친구 목록 / 초대 바로가기 |

#### 주변레이더 vs 친구레이더 위치 공유 독립

두 레이더의 위치 공유는 **완전히 독립**적입니다.
- 주변레이더 ON + 친구레이더 OFF → 주변에는 표시되지만 친구에게는 안 보임
- 주변레이더 OFF + 친구레이더 ON → 친구에게만 표시됨
- 둘 다 ON → 양쪽 모두 표시

---

### 5-3. 그룹 채팅

친구레이더 하단의 **그룹 채팅** 버튼으로 접근합니다. (→ 14장 상세 참조)

---

### 5-4. 위치 공유 동의서

처음 위치 공유를 시도하면 **위치 공유 동의서** 팝업이 표시됩니다.

- 동의 내용을 확인하고 **"동의"** 클릭 후 공유 시작
- 동의 여부는 Supabase `users` 테이블의 `location_consent_at` 컬럼에 저장
- 한번 동의하면 이후에는 팝업이 다시 표시되지 않음

> **위치 공유 동의를 철회하고 싶다면**: 설정 페이지 → 회원 탈퇴 또는 개발자에게 문의

---

### 5-5. 지도 유형 버튼 (위성 + 도로감추기)

레이더탭 상단 탭바 아래에 **두 개의 토글 버튼**이 있습니다.

| 버튼 | 기능 |
|------|------|
| 🛰 위성 | 위성 영상 / 일반 지도 전환 |
| 🛣 도로 | 위성 모드에서 도로 레이어 ON/OFF |

> **도로 감추기** 버튼은 **위성 모드에서만** 활성화됩니다.

## 7. 결산탭 — 수입 & 지출 관리

배달 수입과 지출을 플랫폼별·항목별로 기록·분석하는 가계부 기능입니다.

### 7-1. 월별 결산 개요

결산탭 상단에 **선택된 연·월**과 **요약 카드**가 표시됩니다.

- 당월 총 수입 / 총 지출 / 순이익 한눈에 확인
- 상단 화살표(< >)로 월 이동

탭 구성:
| 탭 | 내용 |
|----|------|
| 달력 | 날짜별 수입/지출 표시 |
| 수입 | 수입 내역 리스트 |
| 지출 | 지출 내역 리스트 |
| 통계 | 차트 분석 |

---

### 7-2. 수입 입력

1. 결산탭 → 우측 하단 **"+ 수입"** 버튼
2. 수입 입력 페이지에서 아래 정보 입력:

| 항목 | 설명 |
|------|------|
| 날짜 | 달력 또는 날짜 피커로 선택 |
| 플랫폼 | 쿠팡이츠 / 배달의민족 / 요기요 / 일반대행 / 기타 |
| 배달 건수 | 해당일 배달 건수 |
| 기본급 | 플랫폼 기본 수수료 |
| 팁 | 고객 팁 합산 |
| 인센티브 | 피크타임·프로모션 보너스 |
| 주행거리 | 오늘 주행거리 (km) |
| 근무 시간 | 시작·종료 시간 또는 총 시간 |
| 날씨 | 맑음 / 흐림 / 비 / 눈 |
| 메모 | 자유 메모 |

#### 입력 방법
- **수동 입력**: 직접 숫자 키패드 입력
- **음성 입력**: 마이크 아이콘 클릭 후 음성으로 입력 ("기본급 삼만오천원")
- **OCR 인식**: 카메라로 영수증·캡처 이미지 스캔 후 자동 인식

---

### 7-3. 지출 입력

1. 결산탭 → 우측 하단 **"- 지출"** 버튼
2. 지출 입력 페이지에서 아래 정보 입력:

| 카테고리 | 아이콘 | 예시 |
|----------|--------|------|
| 유류비 | ⛽ | 주유비, 충전비 |
| 보험료 | 🛡 | 이륜차 보험, 산재보험 |
| 수리비 | 🔧 | 정비·수리 비용 |
| 식비 | 🍽 | 배달 중 식사 |
| 통신비 | 📱 | 데이터·통화료 |
| 주차비 | 🅿 | 주차 요금 |
| 기타 | ⋯ | 기타 비용 |

- **금액** 입력 (계산기 기능 내장)
- **날짜** 선택
- **메모** 선택 입력
- **음성 입력** 지원 ("유류비 오만원")

---

### 7-4. 달력 뷰

- 달력 날짜를 탭하면 **해당일 수입·지출 리스트** 하단에 표시
- 수입이 있는 날: 초록 점 표시
- 지출이 있는 날: 빨간 점 표시
- 달력 월 이동 ↔ 상단 연·월 표시 **양방향 동기화**

---

### 7-5. 통계 차트

통계 탭에서 아래 차트를 확인할 수 있습니다:

| 차트 | 내용 |
|------|------|
| 플랫폼별 파이차트 | 쿠팡이츠/배민/요기요 등 비율 |
| 일별 수입 바차트 | 한 달간 날짜별 수입 흐름 |
| 지출 카테고리 도넛차트 | 유류비/보험 등 지출 구성 |
| 순이익 추이 | 월별 수입 vs 지출 라인차트 |

통계 기간 선택: **주간 / 월간** 탭 전환 가능

---

### 7-6. 목표 설정

- 결산탭 → **"목표 설정"** 버튼 (또는 요약 카드 내 목표 아이콘)
- 월 목표 수입 금액 입력
- 달성률 프로그레스 바 표시

---

### 7-7. CSV 내보내기

- 결산탭 → 우측 상단 **공유 아이콘**
- 해당 월의 수입·지출 내역을 **CSV 파일**로 내보냄
- 카카오톡·이메일·Google Drive 등으로 공유 가능

---

## 8. 정비탭 — 차량 관리

결산탭 내 **"정비"** 탭(4번째 탭)에서 이륜차 유지보수를 관리합니다.

### 8-1. 차량 등록

처음 정비탭 진입 시 **차량 등록 화면**이 표시됩니다.

1. **"+ 차량 추가"** 버튼 클릭
2. 차량 정보 입력:
   - 차량명 (예: 혼다 PCX125)
   - 차종 유형 (오토바이 / 자전거 / 킥보드)
   - 현재 주행거리 (km)
   - 구입일 (선택)
3. 저장 클릭

> 여러 대의 차량을 등록하고 상단 셀렉터로 전환 가능합니다.

---

### 8-2. 소모품 교체 주기

오토바이 기본 소모품과 권장 교체 주기:

| 소모품 | 아이콘 | 권장 교체 주기 | 예상 비용 |
|--------|--------|---------------|-----------|
| 엔진오일 | 🛢️ | 3,000km / 3개월 | ~30,000원 |
| 에어필터 | 💨 | 10,000km / 12개월 | ~15,000원 |
| 점화플러그 | ⚡ | 10,000km / 12개월 | ~10,000원 |
| 타이어 | 🔄 | 앞 15,000km / 뒤 10,000km | ~150,000원 |
| 브레이크패드 | 🔧 | 15,000km / 24개월 | ~30,000원 |
| 체인/벨트 | 🔗 | 체인 10,000km / 벨트 20,000km | ~50,000원 |
| 체인오일 | 🔩 | 500km / 1개월 | ~5,000원 |
| 냉각수 | 💧 | 20,000km / 24개월 (수냉식만) | ~15,000원 |
| 배터리 | 🔋 | 2~3년 | ~50,000원 |

- 각 소모품 교체 후 **"교체 완료"** 버튼 클릭 → 주행거리 초기화 및 이력 기록
- 교체 주기가 가까워지면 **경고 표시(노란색)** 또는 **위험 표시(빨간색)** 로 강조

---

### 8-3. 정비 이력

- 정비탭 → **"이력"** 탭
- 과거 교체·수리 기록 날짜순으로 표시
- 이력 항목: 날짜, 소모품명, 주행거리, 비용, 메모
- 수기 입력 **"기타 정비"** 추가 가능 (타이어 패치, 기타 수리 등)

---

### 8-4. 주행거리 연동

- 결산탭 수입 입력 시 **주행거리 입력** → 정비 소모품 남은 거리 자동 차감
- 정비 대시보드에서 현재 주행거리와 다음 교체까지 남은 거리 한눈에 확인

## 16. 자주 묻는 질문 (FAQ)

### 16-1. 계정 관련

---

**Q. 이메일 인증 메일이 오지 않아요.**

A. 다음을 확인해 주세요:
1. 스팸/정크 메일함 확인
2. 이메일 주소 오타 여부 확인
3. 로그인 화면에서 "재발송" 버튼 클릭 (있는 경우)
4. 5분 이상 기다린 후에도 오지 않으면 다른 이메일로 재가입 시도

---

**Q. 닉네임을 변경하고 싶어요.**

A. 현재 버전에서는 앱 내 닉네임 변경 기능이 제공되지 않습니다. 변경이 필요하시면 개발자에게 문의해 주세요. (정보탭 → 개발자 정보)

---

**Q. 구글/카카오로 로그인했는데 닉네임 설정 팝업이 안 나와요.**

A. 이미 닉네임이 설정된 경우 팝업이 나타나지 않습니다. 닉네임이 이상하게 설정되어 있다면 개발자에게 문의해 주세요.

---

**Q. 탈퇴했다가 같은 이메일로 재가입할 수 있나요?**

A. 가능합니다. 단, 이전 데이터(수입/지출 기록, 위치메모, 게시글, 친구 관계 등)는 복구되지 않습니다.

---

**Q. 비밀번호를 여러 번 틀렸는데 계정이 잠겼어요.**

A. 일정 횟수 이상 오류 시 일시적으로 잠길 수 있습니다. 비밀번호 재설정 이메일을 통해 새 비밀번호를 설정하면 잠금이 해제됩니다.

---

**Q. 소셜 로그인 이후 이메일/비밀번호 로그인으로 전환할 수 있나요?**

A. 현재 소셜 계정과 이메일 계정의 통합은 지원되지 않습니다. 기존 소셜 로그인 방식을 계속 사용해 주세요.

---

### 16-2. 지도 & 위치 관련

---

**Q. 지도가 로딩되지 않아요.**

A. 다음을 확인해 주세요:
1. 인터넷 연결 상태 확인
2. 앱 강제 종료 후 재실행
3. 기기 재부팅

---

**Q. 내 위치가 지도에 정확하게 표시되지 않아요.**

A. 다음을 확인해 주세요:
1. 기기 설정 → 위치 권한이 "항상 허용" 또는 "앱 사용 중 허용"으로 설정되어 있는지 확인
2. GPS가 활성화되어 있는지 확인
3. 실내에 있을 경우 GPS 신호가 약할 수 있습니다. 야외에서 확인해 주세요.

---

**Q. 위치메모 저장이 안 돼요.**

A. 다음을 확인해 주세요:
1. 인터넷 연결 확인 (주소 변환에 인터넷 필요)
2. 이번 달 위치메모 사용 한도 초과 여부 확인 (정보탭 → 위치메모 통계)
3. 로그인 세션이 만료되었을 수 있습니다. 로그아웃 후 재로그인

---

**Q. 위성 지도로 전환했는데 화질이 나빠요.**

A. 위성 이미지 품질은 지역·확대 수준에 따라 달라집니다. 네이버 지도 데이터 기반으로 제공되며, 배달길 앱에서 별도로 개선할 수 없습니다.

---

**Q. 핀 메모 모드에서 지도를 탭해도 아무 반응이 없어요.**

A. 핀 메모 모드 진입 후 화면 상단에 파란 안내 배너가 표시되어야 합니다. 배너가 보이지 않으면 핀 모드가 정상 진입되지 않은 것입니다. 📌 버튼을 다시 탭해 보세요.

---

### 16-3. 레이더 관련

---

**Q. 레이더에 아무도 표시되지 않아요.**

A. 다음을 확인해 주세요:
1. 내 위치 공유 토글이 **ON** 상태인지 확인
2. 반경 범위가 너무 좁게 설정되어 있지 않은지 확인 (최소 500m)
3. 해당 시간대·지역에 위치를 공유 중인 사용자가 없을 수 있습니다.
4. 위치 공유 동의서에 동의했는지 확인

---

**Q. 내 마커가 지도에 표시되지 않아요.**

A. 위치 공유 토글 ON + GPS 권한 허용 상태에서도 마커가 보이지 않는다면:
- 앱을 강제 종료 후 재실행
- 기기 GPS를 끄고 다시 켜기
- 인터넷 연결 확인

---

**Q. 주변레이더를 ON 했는데 위치 동의서 팝업이 매번 나와요.**

A. 동의 후 "동의" 버튼을 클릭해야 정상적으로 동의가 저장됩니다. 만약 매번 나온다면 SharedPreferences 캐시 문제일 수 있습니다. 앱 데이터 초기화 후 재시도해 주세요.

---

**Q. 친구가 위치 공유를 켰는데 친구레이더에 안 보여요.**

A. 다음을 확인해 주세요:
1. 상대방이 **"친구레이더 전용 위치 공유"**를 ON 했는지 확인 (주변레이더 공유와 별개)
2. 양측이 서로 친구 등록이 되어 있는지 확인
3. 지도 새로고침 (친구 위치 버튼 탭)

---

**Q. 레이더에서 상대방의 이동 수단이 이상하게 표시돼요.**

A. 상대방이 앱에서 이동수단을 설정하지 않았을 수 있습니다. 이동수단 기본값은 오토바이입니다.

---

**Q. 레이더 채팅 메시지가 사라졌어요.**

A. 앱이 백그라운드로 이동한 뒤 2~3분 이상 경과하면 채팅 구독이 초기화될 수 있습니다. 앱을 다시 전면으로 가져오거나 재실행하면 이전 메시지가 복원됩니다. 앱 재실행 시 최근 50개 메시지를 불러옵니다.

---

A. 최대 **25명**까지 추가 가능합니다.

**Q. 친구 요청을 보냈는데 상대방이 못 받는다고 해요.**

A. 다음을 확인해 주세요:
1. 닉네임을 정확하게 입력했는지 확인
2. 상대방이 앱을 설치하고 로그인 상태인지 확인
3. 상대방의 알림 설정 확인

---

**Q. 그룹 방에 비밀번호를 설정했는데 변경하고 싶어요.**

A. 현재 버전에서는 방 생성 후 비밀번호 변경 기능이 없습니다. 방을 삭제하고 새로 만들어 주세요.

---

**Q. 그룹 채팅방에서 강제로 퇴장당했어요.**

A. 방장이 강제퇴장 처리한 경우입니다. 재입장은 방장의 허가가 필요합니다.

---

**Q. 그룹 방을 삭제하면 채팅 내역이 사라지나요?**

A. 그룹 방을 삭제하면 해당 방의 모든 채팅 메시지와 멤버 정보가 영구 삭제됩니다.

---

**Q. 그룹에 친구가 아닌 사람도 초대할 수 있나요?**

A. 현재 초대 기능은 **친구 목록에 있는 사람**만 초대 가능합니다. 또는 비밀번호가 없는 공개 방의 경우 누구나 자유 입장 가능합니다.

---

### 16-5. 결산 & 정비 관련

---

**Q. 수입을 입력했는데 통계에 반영이 안 돼요.**

A. 다음을 확인해 주세요:
1. 선택한 **연·월**이 입력한 날짜와 일치하는지 확인 (상단 월 이동 확인)
2. 앱을 완전히 종료 후 재실행
3. 인터넷 연결 확인 (데이터는 Supabase 서버에 저장됨)

---

**Q. 지출 카테고리에 원하는 항목이 없어요.**

A. "기타" 카테고리에 메모를 상세히 적어 사용할 수 있습니다. 카테고리 추가는 건의사항 게시판에 남겨주시면 검토하겠습니다.

---

**Q. 음성 입력이 작동하지 않아요.**

A. 다음을 확인해 주세요:
1. 기기 설정 → 배달길 앱 → 마이크 권한 허용
2. 조용한 환경에서 또렷하게 말해 주세요.
3. 예) "기본급 삼만오천원 배달 십오건"

---

**Q. 수입/지출 내역을 수정하고 싶어요.**

A. 해당 내역 탭 → **"수정"** 버튼 클릭 후 수정 가능합니다.

---

**Q. 정비 탭에서 차량을 여러 대 등록할 수 있나요?**

A. 가능합니다. 정비탭 상단 차량 셀렉터에서 **"+ 차량 추가"**를 선택하면 됩니다. 등록된 차량은 상단 셀렉터로 전환하여 관리합니다.

---

**Q. 엔진오일 교체 후 '교체 완료' 처리를 했는데 주행거리가 초기화가 안 돼요.**

A. 결산탭 수입 입력에서 **주행거리 항목**을 입력해야 정비탭의 주행거리 카운터가 정상 작동합니다. 주행거리 입력 없이 교체 완료 처리 시 시간 기준으로만 초기화됩니다.

---

**Q. CSV 내보내기 파일이 깨져서 열려요.**

A. CSV 파일을 Excel로 열 때 **인코딩 설정**이 필요할 수 있습니다.
- Excel → 데이터 → 외부 데이터 가져오기 → CSV 파일 선택 → 인코딩 "UTF-8" 선택

---

### 16-6. 커뮤니티 관련

---

**Q. 게시글 이미지가 업로드되지 않아요.**

A. 다음을 확인해 주세요:
1. 기기 설정 → 배달길 앱 → 저장소/파일 접근 권한 허용
2. 이미지 파일 크기가 너무 크지 않은지 확인 (권장: 5MB 이하)
3. 인터넷 연결 확인

---

**Q. 내 게시글이 삭제되었어요.**

A. 신고 누적 또는 관리자 판단으로 삭제되었을 수 있습니다. 부당 삭제라고 판단되면 정보탭 → 개발자 정보로 문의해 주세요.

---

**Q. 건의사항 카테고리에 비밀번호가 필요해요.**

A. 건의사항 카테고리는 **비밀번호 보호 게시판**으로 운영됩니다. 비밀번호는 커뮤니티 공지 또는 관리자에게 문의해 주세요.

---

**Q. 지역 필터로 우리 동네만 볼 수 있나요?**

A. 상단 **"전국"** 버튼을 탭하면 지역 필터 옵션이 나타납니다. 내 위치 기준으로 동네를 필터링할 수 있습니다. (GPS 권한 필요)

---

**Q. 댓글에 이미지를 첨부할 수 있나요?**

A. 현재 버전에서는 댓글에 텍스트만 입력 가능합니다. 이미지 첨부는 향후 업데이트에서 지원 예정입니다.

---

### 16-7. 알림 관련

---

**Q. 푸시 알림을 받지 못하고 있어요.**

A. 다음을 확인해 주세요:
1. 기기 설정 → 배달길 앱 → 알림 허용 여부 확인
2. 배달길 설정 → 푸시 알림 소리 ON 확인
3. 기기 배터리 최적화 설정에서 배달길 앱을 "최적화 제외"로 설정

---

**Q. 친구 로그인 알림 소리가 너무 자주 울려요.**

A. 설정 → **"친구 로그인 소리"** 토글을 OFF로 변경하면 소리가 울리지 않습니다.

---

**Q. 공지사항 알림이 오지 않아요.**

A. 설정 → **"공지사항 소리"** ON 상태를 확인하고, FCM 권한이 허용되어 있는지 확인해 주세요.

---

**Q. 앱을 닫은 상태에서도 알림을 받을 수 있나요?**

A. 앱이 완전히 종료(강제 종료)된 상태에서도 FCM 백그라운드 알림은 수신됩니다. 단, 일부 기기(배터리 최적화가 강한 기기)에서는 수신이 지연되거나 차단될 수 있습니다.

---

### 16-8. 오류 & 기술 문의

---

**Q. 앱이 갑자기 종료돼요 (크래시).**

A. 다음을 시도해 주세요:
1. 앱 강제 종료 후 재실행
2. 기기 재부팅
3. 앱 업데이트 확인 (Play 스토어)
4. 앱 캐시 삭제: 기기 설정 → 앱 → 배달길 → 저장소 → 캐시 삭제
5. 지속 시 정보탭 → 개발자 정보로 기기 정보와 함께 문의

---

**Q. 로그인 후 흰 화면만 보여요.**

A. 네트워크 연결이 불안정하거나 Supabase 서버 연결 시간이 초과된 경우입니다. 인터넷 연결 확인 후 앱을 재실행해 주세요.

---

**Q. "세션이 만료되었습니다" 메시지가 자주 나와요.**

A. Supabase 인증 토큰 갱신 주기에 따라 발생합니다. 로그아웃 후 재로그인하면 해결됩니다. 자동 로그인 기능이 적용되어 있어 이후에는 자동 갱신됩니다.

---





**Q. 앱 버전은 어디서 확인하나요?**

A. 정보탭 하단 **"오픈소스 라이선스 보기"** 근처에 현재 앱 버전이 자동으로 표시됩니다. (package_info_plus 동적 표시)

---

**Q. 기기를 바꿨는데 데이터가 없어요.**

A. 배달길은 **클라우드 기반(Supabase)** 으로 데이터를 저장합니다. 동일 계정으로 로그인하면 모든 데이터가 자동 복원됩니다. 단, SharedPreferences에 저장된 앱 설정(알림 소리 등)은 기기 교체 시 초기화됩니다.

---

## 17. 개인정보 및 데이터 정책

### 수집하는 정보

| 정보 | 목적 |
|------|------|
| 이메일 주소 | 계정 인증·관리 |
| 닉네임 | 커뮤니티·레이더 표시 |
| GPS 위치 정보 | 레이더 기능 (동의 시에만) |
| 수입·지출 기록 | 결산 기능 |
| 게시글·댓글 | 커뮤니티 기능 |
| 기기 정보 | 오류 분석, FCM 토큰 |
| 프로필 사진 | Supabase Storage 저장 |

### 데이터 저장 위치

- **Supabase (PostgreSQL)**: 사용자 정보, 위치 기록, 수입/지출, 게시글 등
- **Firebase**: FCM 토큰, 인증 (Firebase Auth)
- **기기 내부**: 앱 설정 (SharedPreferences)
- **Supabase Storage**: 이미지 파일

### 데이터 보존 기간

- 계정 활성 기간 동안 모든 데이터 보존
- 회원 탈퇴 시 즉시 영구 삭제
- 탈퇴 후 30일 내 백업 데이터도 삭제

### 위치 정보 특별 안내

- 위치 정보는 **동의서 확인 후에만** 수집
- 위치 공유 OFF 시 즉시 업로드 중단
- 위치 데이터는 실시간으로만 사용되며 장기 보관하지 않음
- GeoHash 기반으로 서버사이드 필터링 처리 (불필요한 데이터 전송 최소화)
